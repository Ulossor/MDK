📘 TypeScript JS-суперсет

1. Где используется?

Фронтенд: React, Angular, Vue (с TS-поддержкой). Бэкенд: Node.js, Deno, Bun. Десктоп: Electron, Tauri. Мобильные: React Native, NativeScript. Инструменты CLI (например, nx, angular-cli). Крупные проекты: VS Code, Slack, Airbnb.

2. Требования к установке

Node.js v16+ (или Deno, Bun). Менеджер пакетов: npm, yarn, pnpm. Компилятор tsc можно установить как глобально, так и локально.

3. Как установить

npm install -g typescript # глобально npm install --save-dev typescript # локально в проект

Для Deno TS работает из коробки, для Bun — встроенная поддержка.

4. Что нужно, чтобы начать писать код?

  • Редактор: VS Code (родная поддержка) или WebStorm.
  • Файл tsconfig.json с настройками компиляции.
  • Команда tsc или использование сборщика (Vite, Webpack, esbuild).
  • Для отладки рекомендуется @types/node и ts-node.

⭐ Ключевые особенности

Статическая типизация с выведением типов, поддержка дженериков, декораторов, enum, утилитарных типов (Partial, Pick, Omit). Отличная интеграция с экосистемой JavaScript.

🟣 Kotlin JVM / мультиплатформа

1. Где используется?

Android — официальный язык. Серверная разработка (Spring Boot, Ktor, Micronaut). Мультиплатформа (Kotlin Multiplatform): iOS, веб, десктоп. Скрипты, DSL для Gradle. Примеры: Google, Netflix, Uber.

2. Требования к установке

Java JDK 11+, предпочтительно OpenJDK или Oracle. Для Android-разработки нужен Android SDK. Рекомендуется IntelliJ IDEA (или Android Studio).

3. Как установить

sdk install kotlin # через SDKMAN # или скачать с kotlinlang.org и добавить в PATH

Для Gradle-проектов достаточно добавить плагин в build.gradle.kts.

4. Что нужно, чтобы начать писать код?

  • IntelliJ IDEA / Android Studio (встроенная поддержка).
  • Или VS Code с плагином Kotlin Language.
  • Компилятор kotlinc и система сборки Gradle или Maven.
  • Создать проект: gradle init с выбором Kotlin.

⭐ Ключевые особенности

Null-безопасность, расширения, корутины (для асинхронности), интеллектуальное приведение типов, совместимость с Java (можно использовать Java-библиотеки).

📦 Популярные фреймворки / библиотеки

Spring BootKtorExposedRoomKoinArrow

📝 Пример кода

🦀 Rust системный

1. Где используется?

Системное программирование (ОС, драйверы), WebAssembly (WASM), сетевые сервисы (Tokio, Actix), игровые движки (Bevy, Amethyst), встраиваемые системы, CLI-утилиты (ripgrep, exa). Используется в Firefox (часть движка), Dropbox, Discord.

2. Требования к установке

rustc и Cargo (менеджер пакетов). Для некоторых платформ нужен C-компилятор (gcc, clang) и системные библиотеки (например, OpenSSL).

3. Как установить

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

После установки выполнить source ~/.cargo/env. Обновление: rustup update.

4. Что нужно, чтобы начать писать код?

  • Редактор: VS Code с расширением rust-analyzer (рекомендуется) или IntelliJ Rust.
  • Создание проекта: cargo new my_project.
  • Сборка: cargo build, запуск: cargo run.
  • Дополнительно: cargo check для быстрой проверки типов.

⭐ Ключевые особенности

Безопасность памяти без сборщика мусора (владение, заимствование, времена жизни). Высокая производительность, отсутствие гонок данных, удобный менеджер пакетов Cargo.

📦 Популярные фреймворки / библиотеки

TokioActixSerdeDieselBevyClap

📝 Пример кода

fn greet(name: &str) -> String { format!("Hello, {}!", name) } fn main() { println!("{}", greet("Rust")); }

🐦 Swift Apple / сервер

1. Где используется?

iOS / macOS / watchOS / tvOS — основная экосистема. Серверная разработка (Vapor, Hummingbird). Системные скрипты. Используется в приложениях Apple, а также в IBM, Lyft, Slack.

2. Требования к установке

На macOS — Xcode (компилятор + SDK). На Linux — Swift toolchain, а также ICU, clang, libicu-dev.

3. Как установить

macOS: xcode-select --install # или скачать Xcode из App Store Linux: скачать .tar.gz с swift.org, распаковать, добавить в PATH

4. Что нужно, чтобы начать писать код?

  • Xcode — полноценная среда со встроенным редактором, отладчиком.
  • Либо VS Code с расширением SourceKit-LSP.
  • Компилятор swiftc и менеджер пакетов swift package.
  • Создание проекта: swift package init --type executable.

⭐ Ключевые особенности

Безопасность типов, опционалы, замыкания, протоколы, расширения, обобщения. Современный синтаксис с акцентом на читаемость. SwiftUI — декларативный UI-фреймворк.

📦 Популярные фреймворки / библиотеки

SwiftUIUIKitVaporAlamofireRealmCombine

📝 Пример кода

func greet(name: String) -> String { return "Hello, \(name)!" } print(greet(name: "Swift"))

🐹 Golang бэкенд / облака

1. Где используется?

Серверные приложения, микросервисы, облачные инструменты (Kubernetes, Docker, Terraform), CLI-утилиты, сетевые сервисы с высокой конкурентностью. Примеры: Google, Uber, Twitch, Dropbox.

2. Требования к установке

Официальный дистрибутив Go для Windows, macOS, Linux. Не требует дополнительных зависимостей (кроме стандартной библиотеки).

3. Как установить

# скачать с go.dev/dl и запустить установщик # или через менеджер пакетов: brew install go # macOS apt install golang # Linux choco install golang # Windows

4. Что нужно, чтобы начать писать код?

  • Редактор: VS Code с плагином Go (от Google) или GoLand.
  • Инициализация модуля: go mod init example.com/hello.
  • Сборка: go build, запуск: go run.
  • Инструменты: gofmt (форматирование), go vet (анализ), go test (тесты).

⭐ Ключевые особенности

Простота синтаксиса, встроенная конкурентность (горутины, каналы), быстрое время компиляции, статическая компиляция в один бинарный файл. Отличная производительность и низкое потребление памяти.

📦 Популярные фреймворки / библиотеки

GinEchoFiberGormCobraViper

📝 Пример кода

package main import "fmt" func greet(name string) string { return fmt.Sprintf("Hello, %s!", name) } func main() { fmt.Println(greet("Go")) }
